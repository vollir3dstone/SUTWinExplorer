KIS Explorer - User Guide

The Base Menu

The Base Menu is the first context menu to appear in the right-click sequence. It holds actions for general file operations, like preparing for copying, renaming, archiving, versioning and scanning. These actions are independent of the file type, and can be seen as black box operations on files and directories. There are operations common to files and directories, and independent of the file type. They are located at the top and at the bottom of the Base Menu. In the middle section, the operations may vary between files and directories, but still are independent of the file type.

The preparation actions for copying, linking and moving

Generally speaking, these actions select the sources of special file operations.
  1. Prepare for copying: This action prepares items for being copied to another location.
  2. Prepare for linking: This action prepares an item for being linked to from another location.
  3. Prepare for moving: This action prepares items for being moved to another location.
Internally, these actions make use of the default Windows behavior for copying, linking and moving files, using the Windows clipboard to store the selected items temporarily.

The actions for copying to the clipboard

The actions copy certain information for the selected items to the Windows clipboard, making it available for pasting elsewhere.
  1. Copy names: This action copies the names of the selected items to the clipboard.
  2. Copy paths: This action copies the full paths of the selected items to the clipboard.
  3. Copy contents: This action copies the contents of the selected items to the clipboard.

The actions for textual change of identy

These actions allow for textual modifications of the identity of the selected items, like name and location/path.
  1. Rename: This action allows editing the name of the selected items.
  2. Relocate: This action allows editing the location/path of the selected items.
